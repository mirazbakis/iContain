## Longer post (Reddit, forums)

**iContain: run Simulator builds and IPAs inside one app on your iPhone (free, open source)**

I made iContain to test apps on the device I'm actually holding. It loads an imported app into its own container, so the app runs without being installed:

- Import an .ipa, .xcarchive, or a .app built for the iOS Simulator, which is converted to run on the device
- Test mode: run it as an iPhone SE, Pro Max or iPad, in light or dark mode
- Simulated location per app, or for the whole device through LocalDevVPN
- Every app shares iContain's one App ID, so a free Apple ID's limits don't apply
- More RAM: switch on the Increased Memory Limit for your App IDs

It's the first release, so bug reports are very welcome.

Site: https://mirazbakis.github.io/iContain/
