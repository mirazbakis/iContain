First version of iContain: run apps inside one app on your iPhone, including builds made for the iOS Simulator.

**Features**
- Import an `.ipa`, `.xcarchive` or zipped `.app`, including Simulator builds, which iContain converts to run on the device
- Test mode: run an app as another iPhone or iPad, in light or dark mode
- Simulated location for apps in iContain, and for the whole device through LocalDevVPN
- More RAM for your App IDs
- Sign with your Apple ID or a `.p12` development certificate

**Before you install:** this is an early version, tested in the iOS Simulator. Sign `iContain.ipa` with AltLoad, AltStore or SideStore. A `.p12` must be from the same team as the certificate iContain is signed with.
